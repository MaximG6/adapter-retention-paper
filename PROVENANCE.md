# Release provenance

This repository packages the paper, code and records from source revision `39f2fbebd1cbb290bcd2ebba32251a842262b6b4` as a fresh release with independent Git history.

The manuscript date is November 2, 2026. The manuscript sources and both PDFs were updated only for that date and the new repository links. Every figure and all raw measurement files are preserved byte-for-byte, including their original dates. The numerical and model-evaluation implementations are unchanged.

Run manifests retain the Git identifiers captured when the experiments ran. Those identifiers and the notebook's revision maps describe the original experiment history, rather than this repository's initial commit.

The README and reproduction guide were reorganized. Tool-specific instructions, the internal review protocol and project administration material were omitted; the dated scientific registrations, experiment entries, corrections, prompt sets, references, license and authorship were retained. The forward-claim regression test uses the original historical manuscript inputs as local fixtures, so it does not require the old Git history.
